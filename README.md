# Эмаль — демо-сайт с админкой (локально)

Демо-проект, компания вымышленная.

## Запуск (нужны Node.js и Python)

Откройте папку проекта в терминале и запустите **в двух отдельных окнах**:

1. Сайт: `npm run site` → http://localhost:8080/
2. Сервер админки: `npm run cms`

Админка: http://localhost:8080/admin/ → кнопка «Login» → раздел «Содержимое сайта».

Первый раз: `npm install`.

## Где что лежит
- `content/*.json` — все тексты, цены, услуги, отзывы, FAQ, контакты
- `images/uploads/` — загруженные фото
- `admin/config.yml` — настройка полей админки

Админка работает только на этом компьютере. Для публикации в интернет
потребуется заменить `backend` в `admin/config.yml` (см. документацию Decap CMS).
